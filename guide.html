ChatGPT / Codex

Skills를 지원하는 환경에서 ‘KDCA 보도자료 작성’을 사용합니다. 배포 패키지에는 작성 지침·서식·Python 생성기가 들어 있습니다.

플러그인 패키지 받기

모든 ChatGPT 계정에서 ZIP 설치를 지원하는 것은 아닙니다. 개인 Skill 설치와 공개 플러그인 디렉터리 등록은 서로 다른 절차입니다.

Claude

코드 실행 기능을 켜고 사용자 Skill 업로드에서 아래 ZIP을 등록합니다. 설치 후 새 대화에서 원문을 입력하세요.

Claude Skill 받기

ZIP 최상위의 kdca-press 폴더를 유지하세요. 계정이나 조직에서 Skill·코드 실행을 허용해야 합니다.

Gemini Spark / Skills

Gemini의 설정 → Skills에서 사용자 Skill을 추가하고 아래 ZIP을 등록합니다. 필요한 서식과 코드가 들어 있어 스크립트가 인터넷에 접속할 필요가 없습니다.

Gemini Skill 받기

개인 계정에 기능이 순차 제공되고 있습니다. 현재 Google 안내상 사용자 정의 MCP 앱은 미국·영어 조건이 있으므로 한국에서는 Skill을 우선 사용하세요.

원격 MCP 연결

본인 PC를 MCP 서버로 설정하기

운영자가 게시한 HTTPS 주소의 /mcp를 AI의 사용자 정의 MCP 설정에 등록하고 로그인합니다. 생성 파일은 30분 이내에 내려받습니다.

서버가 아직 배포되지 않았다면 Skill만으로 시작할 수 있습니다. GitHub 저장소 주소는 MCP 접속 주소가 아닙니다.

파일은 재시작 시 사라집니다. PC 설치기는 인증을 보존합니다. 기본 메모리 설정에서는 재연결이 필요합니다.

원문을 넣고 이렇게 요청하세요.

“아래 공개 원문을 KDCA 보도자료로 다듬고 HWPX로 만들어 줘. 없는 발언·날짜·수치는 만들지 말고, 확인할 정보는 따로 알려 줘.”

심포지엄·통계발표·사업발표 원문을 지원합니다. 코드 실행도 MCP도 사용할 수 없는 환경에서는 본문 초안까지만 제공합니다.

확인한 범위

세 유형의 실제 작성·HWPX 생성, 표준 MCP 클라이언트 연결, 다른 사용자 파일 접근 차단·링크 만료를 시험했습니다. 각 AI 서비스 계정에서의 설치·다운로드와 한컴오피스에서의 열기·저장 시험은 아직 완료하지 않았습니다.

자동 검사는 문장의 의미 전체를 보증하지 않습니다. 배포 전 수치·대상·발언·문의처를 원문과 대조하세요.
