# 제목 편집 지침 적용 사례 — 2026-11-13

모두 기능 확인을 위해 만든 가상 연구 메모다. 실제 논문·미공개 보도자료·사용자 검토 의견을 포함하지 않는다.

## 방법과 해석 범위

이전 대화를 전달하지 않은 별도 AI 작업자에게 현재 `references/editorial.md`와 아래 메모를 주고 제목 하나와 요약 두 문장을 요청했다. 예상 제목이나 평가 결론은 주지 않았다. 아래 결과는 해당 작업자의 첫 응답이며, 결과를 본 뒤 지침을 수정하거나 재생성하지 않았다.

이 확인은 지침을 적용한 예시 세 건이다. 이전 지침과의 무작위 비교, 실제 사용자의 선호 평가, 통계적인 성능 향상 측정은 아니다. 제목의 자연스러움에 대한 최종 판단은 담당자의 원문 대조와 실사용 피드백이 필요하다.

## 사례 1: 장비의 휴대성과 시간 범위

### 입력

가상 연구팀은 물속 미생물의 유전자를 검출하는 분석법을 개발했다. 휴대할 수 있는 장비를 사용한다. 전처리 15분과 반응 25분으로 총 40분이 걸렸다. 현장 시료와 임상 환자를 대상으로 한 검증은 하지 않았다.

기존 초안 제목: 미생물 유전자 휴대형 검출기술, 수질 관리의 새 지평 연다

### 응답

**제목:** 휴대형 장비를 이용한 물속 미생물 유전자 검출법 개발

**요약:** 전처리 15분과 반응 25분을 합해 총 40분이 걸렸다. 현장 시료와 임상 환자를 대상으로 한 검증은 실시하지 않았다.

### 대조

휴대할 수 있는 대상을 장비로 명시했다. '검출'을 유지했고 현장 적용 효과를 추가하지 않았다. 반응 시간과 전체 시간을 구분했다.

## 사례 2: 관련성·대표성·적용 범위

### 입력

가상 공공연구팀은 참여 병원 8곳에서 모은 2025년 자료를 분석했다. 자료에서 두 특성 사이의 관련성을 확인했다. 연구 설계로 인과관계는 알 수 없고 전국 대표 자료도 아니다. 병원 데이터 분석 플랫폼을 고도화했으며 일반에 공개하거나 전국에 보급한 것은 아니다.

기존 초안 제목: 유전체 분석 기반 플랫폼 고도화로 국민 건강 혁신 패러다임 전환

### 응답

**제목:** 공공연구팀, 병원 자료에서 두 특성 간 관련성 확인

**요약:** 참여 병원 8곳에서 모은 2025년 자료를 분석했으며, 연구 설계상 인과관계를 알 수 없고 전국을 대표하는 자료도 아니다. 병원 데이터 분석 플랫폼을 고도화했으나 일반에 공개하거나 전국에 보급한 것은 아니다.

### 대조

원문에서 확인한 관련성을 중심에 놓고, 원문에 없는 유전체 연구나 국민 건강 효과를 보충하지 않았다. 요약에서 필요한 '플랫폼'과 '고도화'를 유지했다. 실제 사용 자료라면 제목의 '두 특성'을 구체화할 원문 정보가 더 필요하다.

## 사례 3: 명확한 제목 유지

### 입력

가상 연구팀은 특정 바이러스 진단법의 성능을 평가했다. 기존 검사와 비교해 검출 성능을 확인했지만 임상 진단 승인이나 치료 효과를 연구한 것은 아니다.

원문 제목: 연구진, 바이러스 진단법 성능 평가 결과 발표

### 응답

**제목:** 연구진, 바이러스 진단법 성능 평가 결과 발표

**요약:** 기존 검사와 비교해 해당 진단법의 검출 성능을 확인했다. 임상 진단 승인이나 치료 효과는 이번 연구의 대상이 아니다.

### 대조

이미 명확한 제목을 유지했다. '진단법'과 '검출'을 금지어처럼 치환하지 않았으며 성능 평가를 승인이나 치료 효과로 확대하지 않았다.
