# 가상 원문 기반 작성 시험

현재 실행 환경에서 Skill과 원문만 제공해 새로 작성한 결과입니다. 세 플랫폼의 모델 비교 시험이나 실제 기관 발표 자료가 아닙니다. 통계 첫 결과 이후의 지침 개선은 ../../docs/QUALITY.md를 참고하세요. HWPX의 가상 자료 표시는 문서 머리말과 꼬리말에서 확인할 수 있습니다.

본문 Markdown과 입력 JSON은 새 작성 결과를 그대로 보존했습니다. 대표 세 유형의 HWPX·검사 JSON만 최종 생성 엔진으로 다시 만들었습니다. 첫 통계 결과의 파일은 당시 출력을 보존합니다.
