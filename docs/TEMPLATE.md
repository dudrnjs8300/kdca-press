# 실제 KDCA 양식 반영 — v0.5.0

기준은 사용자가 제공한 2026년 10월 8일 조간 보도자료 HWPX입니다. 내용을 넣기 전에 원본에서 고정 양식을 추출합니다.

| 요소 | 반영 방식 |
| --- | --- |
| 상단 질병관리청·대체불가 대한민국 | 원본 이미지와 표 안의 크기·위치 보존 |
| 제목 | 함초롬돋움 26pt, 굵게, 원본 자간·문단 스타일 |
| 요약 | 함초롬바탕 14pt, 원본 요약 스타일 |
| 본문 | 바탕 14pt, 원본 문단 스타일(줄 간격 170%) |
| 배포 시점·담당 정보 | 기존 표 사용, 제공되지 않은 값은 빈칸 |
| 꼬리말 | 원본 건강한 동행 슬로건·1339 이미지, 양쪽 페이지 반복 |
| 쪽번호·쪽 여백 | 원본 가운데 아래 쪽번호 및 A4 여백 보존 |
| 시험용·초안·AI 작성 표기 | 자동으로 삽입하지 않음 |

원본의 연구 내용·연구 그림·인명·연락처·작성자 메타데이터와 이전 미리보기는 제거합니다. 미제공 정보는 `.review.json`의 확인 목록으로 남습니다.

## 확인 방법

`python3 test/template_test.py`는 이미지 네 개와 스타일 XML의 원본 해시, 반복 꼬리말, 쪽번호, 원본 내용 유출 및 불필요한 문구가 없는지 검사합니다. 이미지가 제거된 문서를 검증기가 거부하는지도 확인합니다. 기존 본문·표 보존 시험 및 MCP SDK 시험도 유지합니다.

Kordoc의 SVG는 참고 미리보기입니다. 이 실행 환경에는 원본의 모든 한글 글꼴이 설치되어 있지 않으며, Kordoc의 줄 나눔·쪽번호 표시는 한컴과 차이가 있습니다. HWPX 자체에는 원본 글꼴 참조와 쪽번호가 보존됩니다. 한컴오피스에서 열기·저장·재열기 검증은 아직 하지 못했습니다.
