# 편집 품질 검증

자동 시험은 파일·수치 규칙과 MCP 통신을 검증합니다. 글의 품질은 별도로 원문과 작성 결과를 대조했습니다.

## 서로 다른 두 종류의 예시

- `examples/*.json`: 가상 원문과 사람이 검토한 기준 draft. 동일 입력의 구조·생성 회귀 시험용입니다.
- `evals/forward/`: 새 대화의 AI 작업자에게 Skill과 원문만 주어 얻은 작성 결과입니다. 기준 draft나 예상 답안을 제공하지 않았습니다. 현재 실행 환경의 시험이며 Claude·Gemini 모델을 실행한 결과는 아닙니다.

통계의 첫 결과는 가상 자료 안내를 리드에 길게 넣어 핵심 결과가 흐려졌습니다. 가상 자료 표시는 문서 머리말·꼬리말에서 처리하고 리드는 발표 내용에 집중하도록 Skill을 수정했습니다. 새 대화에서 다시 작성한 결과가 `statistics/`에 있습니다. 첫 결과는 `statistics-first-pass/`에 남겨 수정 경위를 확인할 수 있습니다.

## 대조한 주요 사실

| 유형 | 확인한 항목 |
| --- | --- |
| 심포지엄 | 감시자료 현장 활용 목적, 일시·대상·약 120명, 신청 기간, 미정 신청 방법·기관장 발언을 만들지 않음 |
| 통계 | 동일 14개 기관, 만 18세 이상, 환자별 연간 첫 분리주, 5.0→6.0→7.0%, 전년 대비 1.0%p와 내성 건수 증가율 22.5% 구분 |
| 사업 | 8개 기관, 1억 2천만 원=기관 지원 8천만 원+공동 운영 4천만 원, 자문 16회와 교육 2회 구분, 환자 원자료 중앙 수집 없음 |

통계는 전국 대표성·유의성·원인 단정을 추가하지 않았습니다. 사업은 지원 효과를 확정하거나 인증·정확성을 보증하지 않았고 전국 확대 여부를 미정으로 유지했습니다. 담당자·연락처 등 원문에 없는 배포 정보는 확인 항목으로 남겼습니다. 심포지엄 첫 결과 제목의 가상 표시처럼 편집자가 추가로 조정할 표현은 남아 있습니다.

## 자동 시험의 의미

공통 엔진은 세 유형을 반복 생성해 동일 결과를 확인하고, 새 숫자·단위 변경·조작 인용·원문에 없는 근거·잘못된 표·제어문자 입력을 거부하는지 시험합니다. 표준 SDK로 stdio와 Streamable HTTP를 실제 연결해 생성·resource 읽기·다운로드 해시 일치·사용자 격리·만료를 확인합니다. 이전 v0.1의 인증·문서 검사는 회귀 시험으로 유지합니다.

HWPX 내부 구조·스타일 참조·본문과 표 보존을 검사합니다. Kordoc SVG는 참고 조판이며 한컴오피스 조판 인증이 아닙니다. 분량을 2쪽에 강제로 맞추거나 이를 위해 원문 사실을 삭제하지 않습니다.

## 플랫폼별 최종 평가

동일 source만 ChatGPT·Claude·Gemini에 제공합니다. 설치/로그인부터 HWPX 다운로드까지 끝난 환경만 실제 연결 완료로 표시합니다. 모델·날짜·원문·최종 초안·수정 요청·한컴 재열기 결과를 남깁니다.

사람은 제목의 핵심, 리드의 명료성, 문단 전개, 수치·대상·계획 수준 보존, 해석 범위, 전문어·상투어를 평가합니다. 없는 발언, 수치 오류, 인과·대표성 과장이 있으면 문장 유창성과 관계없이 실패입니다. 같은 숫자를 잘못된 대상에 연결한 오류와 부정의 의미 전환은 자동 검사만으로 보증할 수 없습니다.

## 마지막 화면 확인

세 결과를 현재 엔진으로 다시 조판해 Kordoc SVG에서 본문·표의 잘림과 겹침을 확인했습니다. 심포지엄·통계·사업 모두 2쪽이고 렌더러 경고가 없습니다. 원문이나 초안의 내용을 줄여 분량을 맞추지 않았습니다. 담당 부서·담당자·연락처가 전부 미정일 때는 빈 문의처 표 대신 확인 문구 한 줄을 사용해 문의처만 단독 페이지에 남는 현상을 줄였습니다. 정보가 제공되면 문의처 표를 사용합니다. 실제 한컴 쪽 나눔은 달라질 수 있습니다.

Claude·Gemini·플러그인 패키지는 각각 새 임시 디렉터리에 압축을 풀고 Python 격리 모드로 생성기를 실행해 외부 경로·추가 패키지 의존이 없는지 확인했습니다.
