KDCA 보도자료 작성 도구 v0.5.2

MCP 서버가 전달하는 제목 편집 지침과 검토 항목을 보강했습니다. 기존 원격 MCP 연결과 도구 입력을 유지하며, 익숙한 표현과 자연스러운 수식 관계를 고르고 필요한 전문용어·수치·연구 범위를 보존하도록 안내합니다. 일부 제목 표현은 참고 경고로 반환하고 담당자가 확인할 항목을 제공합니다.

AI는 작성·퇴고를 돕는 보조도구입니다. 사용하거나 배포하기 전에 원문과 대조하여 사실·수치·용어·제목·인용문을 반드시 검토하고 기관의 검토·승인 절차를 거쳐야 합니다. 자동 검사 통과나 파일 생성은 정확성 또는 배포 승인을 뜻하지 않습니다.

이 버전의 시험과 남은 한계는 [검증 현황](STATUS.md) 및 [제목 적용 사례](../evals/headlines/2026-11-13.md)를 참고하세요. 기존 오프라인 Skill은 새 패키지가 필요하며, 원격 MCP 이용자는 업데이트된 서버의 지침과 검사 결과를 받습니다.

## 공통 구성

- Skill과 MCP가 동일한 Python 검사·HWPX 생성 코드를 사용합니다.
- ChatGPT/Codex용 플러그인, Claude용 Skill, Gemini용 Skill 배포물을 제공합니다.
- stdio와 Streamable HTTP MCP, OAuth/PKCE, 만료되는 파일 전달을 구현했습니다.
- 영구 문서함 없이 실행합니다. Skill은 별도 서버·추가 Python 패키지가 필요 없습니다.
- 심포지엄·통계발표·사업발표 가상 원문 및 새 AI 작성 시험 결과가 포함되어 있습니다.

설치 전 docs/STATUS.md와 docs/DEPLOYMENT.md를 확인하세요. 표준 MCP 시험과 각 서비스 계정별 실제 설치 시험은 다릅니다. 한컴오피스에서의 최종 조판 검증은 아직 완료하지 않았습니다.

기관 공식 서비스가 아닌 개인 개발 도구입니다. PDF는 생성하지 않습니다.
