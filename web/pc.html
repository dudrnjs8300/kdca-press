준비할 것

Windows의 Ubuntu/Debian WSL2, 켜 두고 사용할 PC, Cloudflare에서 관리하는 도메인, GitHub OAuth App이 필요합니다.

서버 PC에만 설치합니다. 이용자는 지원되는 AI 계정에서 HTTPS MCP 주소를 연결합니다. 도메인·전력 비용과 플랫폼별 이용 조건은 별도입니다.

재시작 후에도 연결 유지

로그인·OAuth 인증 정보는 PC에 저장하고 문서는 임시로 전달합니다. 생성 파일은 최대 30분, 또는 서버 재시작 전까지만 다운로드할 수 있습니다.

Windows 로그인 시 자동 시작하며 PC가 절전·종료되면 사용할 수 없습니다.

설치 순서

  1. WSL2와 systemd를 준비합니다.
  2. GitHub 코드를 받고 WSL 설치기를 실행합니다.
  3. Cloudflare의 고정 HTTPS 주소와 GitHub OAuth App을 만듭니다.
  4. 설정 프로그램에 주소·인증 정보를 입력하고 서비스를 시작합니다.
  5. Windows 자동 시작을 등록하고 예시 3종을 생성합니다.
  6. 각 AI에서 MCP 연결과 실제 HWPX 다운로드를 확인합니다.

비밀값은 PC의 설정창에 입력합니다. GitHub나 채팅에 넣지 않습니다. 공유기 포트를 직접 열 필요는 없습니다.

검증 범위

인증 보존·토큰 갱신·폐기와 문서 미보존, 표준 MCP의 문서 생성·다운로드를 자동 시험했습니다. 사용자의 Windows PC·실제 도메인·AI 계정에서 연결하는 단계는 설치 후 확인해야 합니다.

이 페이지는 설치 안내입니다. MCP 접속 주소는 본인 도메인을 연결한 뒤 생깁니다.
