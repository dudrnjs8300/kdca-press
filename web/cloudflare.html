무료 Cloudflare MCP

도메인을 구매하지 않고 workers.dev 주소로 연결합니다. PC를 계속 켜 두거나 별도 AI API를 결제할 필요가 없습니다.

문서 생성은 30초 CPU 한도에서

일반 Workers의 10ms 한도는 접속 요청 전달에 적용됩니다. 인증과 HWPX 생성은 무료 SQLite Durable Objects의 기본 CPU 한도 30초를 사용합니다. Skill과 동일한 Python 생성기로 문서를 만듭니다.

로컬 Workers 런타임 검증과 Cloudflare 운영 CPU 실측은 구분합니다. Cloudflare 배포와 공개 접속·인증 안내 검사를 완료했습니다. 로그인 후 실제 AI 문서 생성과 CPU 사용량 확인은 남아 있습니다.

AI에 연결할 MCP 주소

https://kdca-press.on0740.workers.dev/mcp

AI의 사용자 정의 MCP 설정에 위 주소를 입력하고 GitHub로 로그인합니다. 현재는 운영자 dudrnjs8300 계정만 허용합니다.

Cloudflare 배포 권한과 GitHub 로그인용 OAuth App을 저장소의 비공개 설정에 등록한 뒤 GitHub Actions에서 배포합니다. 생성 파일은 30분 동안만 보관하며 영구 문서함은 없습니다.
